# Contributing to YJ Webcam

We welcome contributions from the community!

## Guidelines
1. **Fork & Branch**: Create a feature branch off `main` (`feature/your-feature`).
2. **Architecture Compliance**: Maintain Clean Architecture separation (Core, Domain, Data, Presentation).
3. **Tests**: Ensure all unit tests in Android (`./gradlew test`) and Windows (`dotnet test`) pass cleanly.
4. **Pull Request**: Submit PR with clear summary and verification details.
