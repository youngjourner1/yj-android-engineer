# Changelog

All notable changes to **YJ Webcam** will be documented in this file.

## [1.0.0] - 2026-08-08
### Added
- Complete Clean Architecture Android app with Jetpack Compose & CameraX.
- WinUI 3 Desktop Client (.NET 8) with MVVM Toolkit.
- Native C++ Windows Virtual Camera MediaFoundation Driver DLL.
- WebRTC & USB ADB dual low-latency streaming pipeline.
- On-device AI suite: Background blur/removal, auto-framing, low-light boost.
- ECDH P-256 key exchange & AES-256-GCM encrypted protocol.
- Room database & DataStore settings persistence.
- Diagnostics dashboard, performance charts, and test suites.
- Automated PowerShell build scripts and Inno Setup installer package.
